# Blog API
This is a mono-repo containing three projects. It is part of the [Odin Project](https://www.theodinproject.com) full stack JavaScript curriculum.

**Blog API**
This manages all CRUD functionalities with authentication, posts, tags, and comments.

**Blog**
This frontend is where users can read posts and comment their thoughts.

**Blog Author**
A frontend where users can create and manage their posts and account.

## Built With
**Frontend**
- React
- React Router
- HTML/CSS

Backend
- NodeJS
- Express
- Prisma ORM
- Passport
